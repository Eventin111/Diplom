# Backend-подпроект (`backend`)

Этот каталог содержит FastAPI backend для проекта SwipeIt: API, работу с базой данных, схемы, репозитории, интеграцию с S3/MinIO и обертку над ML-сервисом виртуальной примерки.

## Основные файлы

- **`.coveragerc`** — конфигурация покрытия для backend unit-тестов.
- **`pytest.ini`** — настройки `pytest` для запуска backend тестов.
- **`requirements-test.txt`** — минимальный набор зависимостей для backend unit-тестов и coverage.
- **`alembic.ini`** — базовая конфигурация Alembic для миграций базы данных.
- **`run_server.py`** — вспомогательный скрипт запуска backend с корректной настройкой `PYTHONPATH` и подключением `ml/`.
- **`run_migrations.py`** — программный запуск миграций Alembic и создание новых ревизий.
- **`create_tables_simple.py`** — упрощенный скрипт создания таблиц в БД без Alembic.
- **`create_test_data_no_s3.py`** — заполнение базы тестовыми данными без загрузки файлов в S3.
- **`restore_database.py`** — восстановление базы данных из резервного состояния/дампа.
- **`clean_databases_completely.py`** — полная очистка данных из базы.
- **`check_db.py`** — базовая проверка подключения и состояния базы.
- **`check_db_status.py`** — дополнительная диагностика состояния БД.
- **`check_existing_data.py`** — просмотр существующих данных в базе.
- **`update_existing_media_dimensions.py`** — пересчет и обновление размеров уже сохраненных медиафайлов.

## Папка `app/`

Основной код backend-приложения.

### Корневые файлы `app/`

- **`main.py`** — точка входа FastAPI-приложения: создает `app`, подключает CORS, роуты и обработчики ошибок.
- **`architecture.py`** — краткое описание архитектурных слоев проекта и настройка путей импорта.
- **`__init__.py`** — делает каталог `app` Python-пакетом.

## `app/api/` — HTTP-слой (Presentation Layer)

- **`routes.py`** — собирает общий `APIRouter` и подключает все API-модули версии `v1`.
- **`deps.py`** — функции зависимостей FastAPI: сессия БД, фабрики репозиториев и прочие внедряемые зависимости.
- **`__init__.py`** — пакет API-модулей.

### `app/api/v1/`

- **`auth.py`** — эндпоинты регистрации, логина и получения текущего пользователя.
- **`media.py`** — загрузка медиафайлов, определение MIME-типа и получение информации о медиа.
- **`garments.py`** — создание и чтение карточек одежды.
- **`feed.py`** — работа с лентой: создание постов, получение feed, лайки.
- **`tryon.py`** — HTTP-интерфейс виртуальной примерки: принимает изображения, создает `TryOnRequest`, вызывает use case.
- **`__init.__.py`** — служебный файл пакета `v1` (сейчас имеет нетипичное имя и не участвует в импортах как обычный `__init__.py`).

## `app/application/` — прикладная логика (Application Layer)

- **`__init__.py`** — пакет application-слоя.

### `app/application/dto/`

- **`tryon_dto.py`** — DTO для сценария виртуальной примерки: `TryOnRequest` и `TryOnResponse`.
- **`__init__.py`** — пакет DTO.

### `app/application/use_cases/`

- **`tryon_use_case.py`** — основной use case backend: валидирует входные данные примерки, подготавливает изображения, вызывает ML-сервис, формирует ответ.
- **`__init__.py`** — пакет use case-модулей.

## `app/core/` — кросс-секционные компоненты

- **`config.py`** — загрузка настроек из переменных окружения и `.env`, свойства для URL базы и S3.
- **`db.py`** — создание async SQLAlchemy engine, session factory и базового класса моделей.
- **`security.py`** — создание JWT-токенов и получение текущего пользователя по токену.
- **`hashing.py`** — хеширование и проверка паролей через `passlib`.
- **`s3.py`** — клиент для MinIO/S3, загрузка файлов и проверка bucket.
- **`image_processor.py`** — утилиты для чтения размеров, формата и ориентации изображений.
- **`errors.py`** — глобальные обработчики ошибок FastAPI и унификация ответов об ошибках.
- **`logging.py`** — базовая настройка логирования.
- **`__init__.py`** — пакет core-модулей.

## `app/infrastructure/` — интеграции с внешними системами

- **`__init__.py`** — пакет infrastructure-слоя.

### `app/infrastructure/ml/`

- **`ootd_service.py`** — backend-обертка над ML-пайплайном OOTDiffusion: лениво инициализирует модель и выполняет `try_on`.
- **`__init__.py`** — пакет ML-инфраструктуры.

## `app/models/` — ORM-модели базы данных

- **`user.py`** — модель пользователя.
- **`media.py`** — модель медиа-объекта.
- **`garment.py`** — модель одежды.
- **`feed.py`** — модель элемента ленты.
- **`likes.py`** — модель лайков.
- **`tryon.py`** — модель сессии виртуальной примерки.
- **`mixins.py`** — общие mixin-классы для моделей, например временные поля.
- **`__init__.py`** — пакет ORM-моделей.

## `app/repositories/` — доступ к данным

- **`base.py`** — базовый асинхронный репозиторий с общими CRUD-операциями и обработкой ошибок SQLAlchemy.
- **`user_repo.py`** — операции с пользователями: поиск по email/username, аутентификация, обновление.
- **`media_repo.py`** — операции с медиа, загрузка файлов через S3 и выборки по размерам.
- **`garment_repo.py`** — создание, обновление и поиск одежды.
- **`feed_repo.py`** — создание feed-элементов, связывание медиа и построение ленты со статистикой.
- **`like_repo.py`** — работа с лайками: создание, удаление, переключение состояния, счетчики.
- **`tryon_repo.py`** — работа с сессиями виртуальной примерки и их статусами.

## `app/schemas/` — Pydantic-схемы API

- **`user.py`** — схемы пользователя, регистрации, логина и токена.
- **`media.py`** — схемы медиафайлов, загрузки и ответа с `public_url`.
- **`garment.py`** — схемы одежды и валидация названия/связанных полей.
- **`feed.py`** — схемы постов ленты, пагинации и статистики.
- **`social.py`** — схемы лайков и агрегированной статистики.
- **`tryon.py`** — схемы сессии примерки и результата.
- **`__init__.py`** — пакет схем.

### `app/domain/entities/`

## Папка `tests/`

Unit-тесты backend.

- **`conftest.py`** — общая тестовая настройка: пути импорта и обязательные переменные окружения.
- **`test_tryon_use_case.py`** — тесты `TryOnUseCase`.
- **`test_backend_ootd_service.py`** — тесты backend-обертки над ML-сервисом.
- **`test_hashing_and_security.py`** — тесты хеширования паролей и JWT-аутентификации.
- **`test_image_processor.py`** — тесты утилит обработки изображений.
- **`test_s3_client.py`** — тесты клиента S3/MinIO с заглушками внешнего хранилища.
- **`test_schemas.py`** — тесты Pydantic-схем и их валидаторов.
- **`test_errors_and_config.py`** — тесты конфигурации приложения и обработчиков ошибок FastAPI.

## Как читать backend по порядку

Если нужно быстро разобраться в проекте, удобно идти в таком порядке:

1. **`app/main.py`** — как собирается приложение.
2. **`app/api/routes.py`** и **`app/api/v1/*.py`** — какие есть HTTP-эндпоинты.
3. **`app/application/use_cases/tryon_use_case.py`** — пример прикладной бизнес-логики.
4. **`app/repositories/*.py`** — как backend работает с базой данных.
5. **`app/core/*.py`** — конфиг, безопасность, S3, ошибки.
6. **`app/infrastructure/ml/ootd_service.py`** — как backend связывается с ML-подпроектом.
